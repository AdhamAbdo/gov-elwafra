AFTER CREATING EACH AUTH USER
------------------------------
1. Copy the new Auth UUID from Supabase Authentication > Users.
2. Create a profile:

   insert into public.user_profiles (id, display_name, active)
   values ('AUTH_USER_UUID', 'DISPLAY_NAME', true);

3. Assign the role to the matching [DEMO] company:

   insert into public.user_company_roles (user_id, company_id, role)
   select 'AUTH_USER_UUID', id, 'ROLE_NAME'::app_role
   from public.companies
   where name_ar = 'DEMO_COMPANY_NAME';

4. For a branch-only compliance officer, add branch access:

   insert into public.user_branch_access (user_id, branch_id)
   select 'AUTH_USER_UUID', b.id
   from public.branches b
   join public.companies c on c.id = b.company_id
   where c.name_ar = 'DEMO_COMPANY_NAME'
     and b.name_ar = 'DEMO_BRANCH_NAME';

SYSTEM ADMINISTRATOR SCOPE
--------------------------
Assign the administrator to every [DEMO] company:

insert into public.user_company_roles (user_id, company_id, role)
select 'ADMIN_AUTH_USER_UUID', c.id, 'system_administrator'::app_role
from public.companies c
where c.name_ar like '[DEMO]%';
